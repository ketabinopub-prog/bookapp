Build the APK:
1) Android Studio: open this folder -> Build > Build APK(s)
   (output: app/build/outputs/apk/debug/app-debug.apk)
2) Or push this folder to a GitHub repo -> Actions tab -> "Build APK" -> download artifact "book-apk".

The HTML is at app/src/main/assets/index.html (unchanged). To update content, replace that file.
